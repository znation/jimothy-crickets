Privacy

Jimothy Crickets collects no data.

The game makes no network requests while you play. It has no accounts, ads, analytics, tracking or in-app purchases. Your progress (levels cleared, moons, acorns, upgrades and settings) is saved only on your own device, and you can copy it out yourself with the save code in Settings.

The web version is hosted on GitHub Pages, which, like any web host, receives the usual request information (such as your IP address) when your browser downloads the game. See GitHub's privacy statement. App stores that distribute the game have their own policies.

The game is free and non-commercial, for all ages.
